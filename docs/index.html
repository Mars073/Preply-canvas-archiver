Preply Canvas Archiver

Preply only lets you open a lesson’s Canvas during class. This extension saves it, so your notes stay yours.

What it looks like

What it does

  • Saves in one clickThe archive button stores the page. It also saves on its own a minute after the last edit, so you cannot forget.
  • Keeps every versionThe history panel shows exactly what your tutor added or corrected since the previous one.
  • Reads offlineThe viewer never contacts Preply. Images are copied in, so an archive still works months later.
  • Prints and exportsPrint to PDF, or export a self-contained HTML file you can keep anywhere.
  • Searches properlyAccent- and case-insensitive across a whole classroom: type slonce, find słońce.
  • Speaks your languageEnglish, French, Spanish, Russian, Polish and Chinese, with correct plural agreement in each.

Your notes never leave your browser

There is no server, no account and no analytics, because there is nothing to send anything to. Everything the extension saves is written to your browser’s local storage, on your own machine. Uninstalling it deletes the lot.

The only network traffic it causes goes to preply.com itself, while you are already on a lesson page, to copy the images shown in your Canvas.

Installing before release

Neither store listing is live yet. Until then, clone the repository and run bash tools/package.sh, then:

  • Firefox — about:debugging → This Firefox → Load Temporary Add-on → pick src/manifest.json.
  • Chrome — chrome://extensions → enable Developer mode → Load unpacked → pick dist/chrome/.

Only pages you visit while the extension is active can be captured. There is no way to fetch past lessons retroactively.
