Exportez et sauvegardez vos notes Preply Canvas

Votre Canvas existe peut-être encore quelque part sur Preply. Encore faut-il le retrouver. Enregistrez-en une copie tant que vous y avez accès : vous pourrez la relire hors ligne, l’imprimer en PDF ou l’exporter.

Une salle de classe par professeur, chaque page une seule fois, et toutes ses versions à portée de clic.

Sauvegardez un Canvas Preply tant que vous y avez accès

Pendant le cours, Preply Canvas Archiver ajoute un bouton d’archivage à la barre d’outils du Canvas. Un clic suffit pour enregistrer la page dans votre navigateur. Et si vous oubliez, pas de souci : chaque page que vous ouvrez ou modifiez est enregistrée automatiquement dès qu’elle ne bouge plus pendant une minute. Juste à côté, un bouton d’impression vous permet d’obtenir un PDF avant la fin du cours.

C’est tout ce que l’extension ajoute à Preply, dans le même style que les boutons existants.

Vos notes de cours hors ligne, en PDF ou en HTML

Ouvrez vos archives quand vous voulez depuis l’icône de l’extension, même sans connexion : tout est stocké dans votre navigateur, et Preply n’est jamais contacté. Chaque version d’une page est conservée, et l’historique vous montre ce que votre professeur a ajouté ou corrigé d’une fois sur l’autre.

Chaque page s’imprime proprement en PDF ou s’exporte en un seul fichier HTML, facile à garder, à sauvegarder ou à partager. Et la recherche couvre toute une salle de classe, sans se soucier des accents ni des majuscules.

Rien ne sort de votre navigateur

Ni serveur, ni compte, ni statistiques : il n’y a tout simplement nulle part où envoyer vos données. Tout reste sur votre ordinateur, et désinstaller l’extension efface tout.

Les seules requêtes réseau qu’elle effectue ont lieu sur la page de cours Preply déjà ouverte, pour récupérer les images de votre Canvas.

Questions fréquentes

Comment exporter un Canvas Preply ?

Installez l’extension, puis ouvrez le Canvas de votre cours sur Preply. Cliquez sur le bouton d’archivage, à droite de la barre d’outils du Canvas, ou laissez l’enregistrement automatique faire le travail. Ouvrez ensuite vos archives depuis l’icône de l’extension et choisissez Imprimer / PDF, ou Exporter en HTML dans le menu ⋯.

Peut-on télécharger ses notes Preply Canvas ?

Oui. Chaque page archivée peut être exportée en fichier HTML autonome, images comprises, ou enregistrée en PDF depuis la fenêtre d’impression.

Comment retrouver un Canvas Preply après le cours ?

Toutes les pages enregistrées pendant que l’extension était installée restent dans vos archives : un clic sur l’icône de l’extension, et vous les retrouvez. En revanche, une page que vous n’avez jamais ouverte avec l’extension ne peut pas être récupérée.

Peut-on exporter un Preply Canvas en PDF ?

Oui, de deux façons : avec le bouton d’impression ajouté à la barre du Canvas pendant le cours, ou avec Imprimer / PDF dans vos archives. Dans la fenêtre d’impression du navigateur, choisissez « Enregistrer au format PDF ».

Peut-on relire ses notes Preply hors ligne ?

Oui. Vos archives sont stockées dans le navigateur et ne passent jamais par Internet : vos notes s’ouvrent même sans connexion.

Où sont stockées mes notes ?

Uniquement dans le stockage local de votre navigateur, sur votre ordinateur. Rien n’est envoyé en ligne. Attention : désinstaller l’extension efface les archives, alors exportez d’abord les pages que vous voulez garder.

Les vrais défis techniques

Chaque version est complète

Chaque enregistrement est conservé en entier, indépendamment des autres, et non comme une suite de modifications. Si un fichier est abîmé, vous perdez une version, pas tout l’historique.

Une recherche qui parle polonais

La recherche ignore les accents et les majuscules dans toute la salle de classe, y compris le ł, une lettre qu’aucune normalisation Unicode ne décompose. Tapez slonce, vous trouverez słońce.

Une mise en page fidèle

Les archives reprennent la largeur, la taille et la police de l’éditeur de Preply : les lignes se coupent exactement comme pendant le cours.

Des images qui ne disparaissent pas

Preply sert les images via des liens qui expirent. L’extension les copie au moment de l’enregistrement ; sans cela, vos archives perdraient peu à peu leurs illustrations.

Installer depuis le code source

Le plus simple reste de passer par la boutique de votre navigateur. Mais pour lire le code, le modifier ou essayer la version de master avant sa publication, vous pouvez charger l’extension vous-même, sans attendre les quelques jours de validation des boutiques.

Firefox
Ouvrez about:debugging, puis « Ce Firefox » → « Charger un module complémentaire temporaire… » et sélectionnez src/manifest.json. L’extension disparaît au prochain redémarrage : Firefox n’installe durablement que les extensions signées.
Chrome et Edge
Lancez bash tools/package.sh, ouvrez chrome://extensions (ou edge://extensions), activez le « Mode développeur », cliquez sur « Charger l’extension non empaquetée » et sélectionnez le dossier dist/chrome/.

Aucune compilation, aucune minification : le dossier src/ est exactement ce qui est publié. Le code que vous lisez est celui qui s’exécute.

L’extension n’enregistre que les pages ouvertes après son installation : les cours passés ne peuvent pas être récupérés.
