趁还能访问，保存你的 Preply Canvas。

上课时，Preply Canvas Archiver 会在 Canvas 工具栏上添加一个归档按钮。点一下，页面就保存到你的浏览器里。忘了也没关系：你打开或编辑过的每个页面，在一分钟没有变化后都会自动保存。旁边还有一个打印按钮，下课前就能拿到 PDF。

扩展在 Preply 中添加的全部内容，样式沿用原有按钮。

课堂笔记：离线查看，PDF 或 HTML。

随时点击扩展图标打开归档，没有网络也可以：内容从浏览器中读取，从不连接 Preply。每个页面的所有版本都会保留，历史记录会显示老师相比上一版新增或修改了什么。

任何页面都能打印成整洁的 PDF，或导出为单个 HTML 文件，方便保存、备份或发送。搜索覆盖整个课堂，不区分变音符号和大小写。

数据不会离开你的浏览器。

没有服务器、没有账号、没有统计分析，根本没有可以发送数据的地方。所有内容都保存在你电脑的本地存储中，卸载扩展即全部删除。

它只会在你已经打开的 Preply 课程页面上发出网络请求，用来复制 Canvas 中的图片。

常见问题

如何导出 Preply Canvas？

安装扩展后，在 Preply 上打开课程的 Canvas。点击 Canvas 工具栏右侧的归档按钮，或者让它自动保存。之后点击扩展图标打开归档，选择打印 / PDF，或在 ⋯ 菜单中选择导出为 HTML。

可以下载 Preply Canvas 笔记吗？

可以。每个已归档的页面都能导出为包含图片的独立 HTML 文件，也可以在打印对话框中保存为 PDF。

下课后怎么查看 Preply Canvas？

安装扩展期间保存的页面都会留在归档里，随时点击扩展图标就能打开。没有在安装扩展后打开过的页面无法找回。

可以把 Preply Canvas 保存为 PDF 吗？

可以，有两个入口：上课时扩展在 Canvas 工具栏添加的打印按钮，以及归档中的打印 / PDF。在浏览器的打印对话框中选择“另存为 PDF”即可。

可以离线查看 Preply 笔记吗？

可以。归档保存在浏览器中，阅读界面从不联网，没有网络也能打开笔记。

我的笔记保存在哪里？

只保存在你电脑上浏览器的本地存储中，不会上传到任何地方。卸载扩展会删除归档，所以请先导出想保留的页面。

真正困难的部分。

版本完整独立

每次保存都完整、独立地存储，而不是一串差异记录。某个文件损坏只会损失一个版本，不会牵连之前的历史。

懂波兰语的搜索

在整个课堂中搜索时忽略变音符号和大小写，而 ł 是任何规范化都无法分解的字母。输入 slonce，就能找到 słońce。

换行位置与课上一致

阅读界面还原了 Preply 编辑器的宽度、字号和字体，归档页面的换行与上课时完全相同。

图片不会失效

Preply 通过会过期的链接提供图片。保存页面时会把图片一并复制下来，否则归档会悄悄损坏。

从源代码运行。

三个扩展商店是主要的安装途径，这里是另一条路：阅读代码、修改代码，或在商店上架之前运行 master 上的版本。商店审核要几天，分支则随时可用。

Firefox
about:debugging → 此 Firefox → 临时载入附加组件… → 选择 src/manifest.json。重启 Firefox 后会消失：永久安装需要签名。
Chrome 和 Edge
运行 bash tools/package.sh，然后打开 chrome://extensions（或 edge://extensions）→ 开发者模式 → 加载已解压的扩展程序 → 选择 dist/chrome/

没有构建步骤、没有打包工具、没有压缩：src/ 就是发布的内容。你读到的代码就是运行的代码。

只有在安装扩展后打开过的页面才能被保存，已经结束的课程无法找回。
